# v0.15 外置语音轻量版

## 配置

打开 TXT 书籍 → 底部音色按钮 → 智能语音 → 服务器设置。
服务器基础地址为 HTTPS，不要填 SSH 端口。可以填基础地址或完整
`/v1/audio/speech` 路径。填写你自己服务器的 Bearer API 密钥并保存，
选择「温柔自然 · 1号」或「温柔微嗲 · 4号」试听。
不配置密钥也能正常阅读，系统朗读不依赖此 API。

## 行为和隐私

- 主动朗读或试听才发送文本；没有启动扫描、模型加载或整库上传。
- 手机不再打包或链接 Qwen、MLX、Kokoro、sherpa-onnx。
- 仅 HTTPS，拒绝重定向，避免将密钥发送到重定向地址。
- iOS Keychain / Android Keystore 加密保存密钥，不写入源码或书库导出。
- 手机只保留少量待播分段，停止或换音色会取消客户端请求，丢弃过期响应。
- 取消客户端请求不保证 NAS 已开始的计算同步终止；新请求可能短暂遇到繁忙重试。
- NAS 仍是整段生成后返回 WAV，不是真正流式语音。实测慢于播放，预取不能保证连续无停顿。
- 服务器缓存会保留音频；手机关闭语音不等于删除服务器缓存。
- Android 锁屏长时间听书尚未接入前台媒体服务，不承诺稳定后台运行。

## 章节和性能

- TXT 的章节按钮及前后章跳转；沿用 EPUB 自带目录。
- 章节识别在后台执行，自动语言检测仅针对当前朗读段落，不再扫描全书。
- 不改书籍文件、书库路径、笔记格式或进度键，升级应保留原有数据。
- 原来的本地模型源码仍保留在仓库历史/研究目录，不进入新安装包。

## 验收边界

CI 检查 TXT 解析、语音切分/队列、API 地址校验，以及最终安装包无旧模型。
构建成功不等于 iPhone/Android 真机 UI 已验收。安装后需检查：
导入大 TXT、快速切换章节和音色、生成中暂停/退出、断网、错误密钥、重启恢复阅读位置。
公网带密钥 API 已测试 HTTP 200 和有效音频响应，不等于手机端端到端验收。
