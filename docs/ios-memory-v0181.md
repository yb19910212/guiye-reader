# v0.18.1 连续朗读内存实验修复

用户反馈：iPhone 17 Pro Max 单句正常，连续两三句后显示合并的前台/内存警告。旧提示不能证明是哪一种事件，不把内存泄漏当作已证实根因。

## 改动

- Qwen clone 在保留声码前显式求值；解码前释放 KV 缓存和中间输入，降低生成/解码资源叠加。
- iOS波形解码在各上采样阶段显式求值，缩短大计算图存活期；不修改权重、参考音色或采样参数。实际峰值改善幅度待真机测量。
- 每段生成置于 autoreleasepool，转换成 PCM 后退出作用域，再清理 MLX 可回收缓存。复用模型权重不等于复用上一段生成缓存。
- MLX 回收池由32MB降到8MB；它不是总内存上限，不通过抬高应用内存权限掩盖问题。
- 显示生成前后 MLX 活跃内存、进程历史 MLX 峰值、生成前后 App phys_footprint。MLX 峰值不是 App 峰值。
- 内存警告、前台活动中断分开提示。内存警告取消新生成并安全释放模型，保留待播音频播放后暂停，不无限自动重启模型。
- 200MB磁盘缓存按最近使用时间自动淘汰，保护当前播放与待播文件。整章待播文件本身超预算时清楚提示改用边生成边播放，不删保护文件。
- 实验室新增所选音色连续20段真实推理（中性文本），逐段记录，不读取音频缓存；可取消，高温停止。最后试听一段，不等于20段真实播放器验收。

## 验证范围

新增200次缓存写入/淘汰及待播保护回归；保留已有分段、预缓冲、取消、PCM及TXT回归。Windows无法运行iOS/Metal真机推理；不得把CI编译成功写成iPhone连续推理通过。

真机路径：更多→离线语音实验室→校验→连续生成20段并记录内存。分别测1号/4号，保存最后统计和任何停止提示；再测正文连续播放、取消、切换、章节缓存及锁屏恢复。保持原1号/4号参考录音与模型文件不变。
