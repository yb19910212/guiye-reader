# 开发路线

## Sprint 1–2：可运行基础（当前）

- 双端应用壳与设计基线
- 示例书库、阅读页和阅读进度状态
- 系统离线语音、自动语言、音色和语速
- 双端 CI 构建

## Sprint 3–4：真实文件导入（进行中）

- [x] EPUB / PDF / TXT 文件选择与批量导入
- [x] 文件私有化保存、内容指纹与重复拦截
- [x] TXT 正文阅读和语音联动
- [x] Readium 双端依赖与 Publication 路由基础
- [ ] EPUB / PDF 完整 Navigator 页面
- [ ] 分享菜单导入、元数据、封面和 SQLite 书库
- 大文件与损坏文件测试集

## Sprint 5–6：可靠阅读

- EPUB 排版、主题、分页/滚动
- PDF 单页/连续、目录、缩略图和裁白边
- 稳定 Locator、阅读进度和后台恢复
- 语音与段落位置联动

## Sprint 7–8：知识沉淀

- 高亮、批注、书签
- 笔记中心、搜索、Markdown/HTML 导出
- 从高亮创建复习卡片

## Sprint 9–10：高级语音

- 云端神经语音适配器与服务端短期令牌
- 音频分段缓存、后台播放、锁屏控制和睡眠定时
- 可下载本地语音模型目录

## Sprint 11–12：同步 Beta

- 账户、进度与笔记事件同步
- 冲突处理、版本历史、加密备份与恢复
