# AI 语音模型方案

“内置各种语言模型”实现为可插拔语音目录，而不是把多个大型模型永久打进安装包。

## 引擎层级

| 层级 | MVP | 说明 |
|---|---:|---|
| 系统离线语音 | 是 | iOS AVSpeechSynthesizer、Android TextToSpeech；零额外成本、隐私最好。 |
| 可下载本地模型 | 后续 | 按语言下载，支持磁盘预算、校验、删除和设备能力检测。 |
| 云端神经语音 | 后续 | 高自然度、多角色；按量付费，需用户授权上传文本。 |
| 自定义供应商 | 后续 | 统一适配器，不在客户端写死供应商密钥。 |

## 语言与音色

- 根据段落内容自动识别语言，也允许按书覆盖。
- 中文至少区分普通话、粤语（设备支持时）；英文支持主要区域音色。
- 不支持的语言回退到书籍语言，再回退到设备默认语言。
- 每个音色展示语言、地区、是否离线、模型品质和预计下载大小。

## 安全与版权

- 云端访问令牌由服务端签发短期凭证。
- 不允许克隆真实人物声音，除非具备明确授权和可验证同意。
- 语音缓存加密保存，并提供“一键清除”。
- DRM 内容的朗读能力遵循内容授权策略。
