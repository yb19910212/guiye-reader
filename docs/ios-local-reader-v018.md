# iOS v0.18.0 本地正文朗读

## 范围与行为

- 仅完整内置 iOS 实验包开启 QWEN_LAB；Android、EPUB/PDF 和轻量包不新增本地模型。
- TXT 正文 → 智能语音 → 本地离线音色 → 1号/4号 → 返回正文播放。
- 仍使用固定 Qwen 0.6B 四位权重和原参考录音。无 API 密钥、无下载、无自动联网回退。
- 每段最多 40 个字符，保留原段落 ID 用于阅读位置；不是精确到音频秒的恢复。
- 起播先准备两段；末尾不足两段也会播放。耗尽时重新缓冲两段，显示状态；播放器之外至多两段待播。
- 单一 worker 串行持有模型，段间复用。取消 token 可由主线程置位，旧任务不能污染新队列；异步加载重入由显式占用标记隔离。
- 整章预缓存、按音色与模型版本隔离的 PCM16 磁盘缓存；已有缓存保留，200 MB 上限不变。
- 只在主动朗读时加载；停止/完成释放，离开前台/内存警告停止；高温拒绝新推理。锁屏朗读仍选 API/系统。

## 验证边界

- 用户提供 iPhone 17 Pro Max 短句实测：1号生成3.1秒/音频3.9秒，4号3.4秒/4.2秒。这不是长篇连续播放验收。
- 回归覆盖40字分段重组、Unicode/段落ID、两段起播/单段EOF/重新缓冲、PCM编码限幅/无效值拒绝、缓存持久性与取消token。
- 发布前需等待 macOS Swift 回归、Xcode 编译、最终 IPA 全量模型哈希检查通过。
- 需用户真机验收：断网1×连续10–15分钟、快速切1/4/系统、取消后重启、切章、锁屏返回、阅读滑动、热机与缓存重播。未执行不得声称完成。

## 性能预期

预缓冲减少段间空等，但不提高模型固有速度。高倍速、设备发热或复杂文本可能耗尽缓冲；优先1×，或先缓存本章后播放。正文生成有120秒单段保护和384帧上限，达到上限报错而不播放截断音频。
